# Experimental Results

The associated project paper reports testing in a controlled laboratory environment approximating an examination-hall setting.

## Reported Results

| Test parameter | Result |
|---|---:|
| Active phones tested | GSM 900/1800 MHz and LTE 2100 MHz |
| Test distance range | 5 cm to 60 cm |
| Active-phone detection | Up to 45 cm |
| Idle-phone detection | Approximately 15 cm |
| False-positive rate | 2.4% |
| Wireless latency | 8–12 ms |
| Continuous operation | 8 hours |
| Observed hardware failures | None during reported test |
| Communication dropouts | None during reported test |

## Interpretation

The reported results indicate that the prototype can detect active mobile devices within a defined proximity and can transmit alerts with low latency.

The detection range and false-positive rate are dependent on the deployment environment, sensor position, calibration and nearby electromagnetic/magnetic interference.
