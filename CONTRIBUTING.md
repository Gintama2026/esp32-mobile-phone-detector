# Contributing

This is an academic embedded-systems project. Small, focused improvements are welcome.

## Before opening a pull request

- Explain the change and its purpose.
- Keep hardware pin changes documented.
- Do not claim performance measurements that were not actually tested.
- Include relevant serial output or test conditions for bug fixes.

## Code style

Prefer clear names, short functions, comments around hardware-specific behavior, and configuration constants at the top of the sketch.
